# 阿嬷的频道

用莆仙话（莆田方言）语音点播节目的网页应用。对着手机说节目名，系统自动识别并播放。

## 这个项目是做什么的？

阿嬷（奶奶/外婆）想看戏，但不会打字搜索。这个网页让她直接用莆仙话说出节目名（比如"春草闯堂"、"状元与乞丐"、"江梅妃"），系统就能自动找到并播放对应的节目。

## 两个页面

| 页面 | 用途 | 适合谁 |
|------|------|--------|
| `index.html` | 阿嬷的频道 - 说话点播节目 | 长辈日常使用 |
| `record.html` | 语料录入 - 录制莆仙话帮助训练 | 家人帮忙录音 |

## 如何用手机访问

### 方式一：同一个 WiFi 下（推荐）

1. 在电脑上启动后端服务（见下方说明）
2. 在电脑上启动前端网页
3. 手机连上和电脑同一个 WiFi
4. 用手机浏览器打开 `http://<电脑IP>:8080`

查看电脑 IP 的方法：在电脑终端输入 `ifconfig | grep "inet "`，找到 `192.168.x.x` 的地址。

### 方式二：公网访问（任何地方都能用）

使用 Cloudflare Tunnel，把电脑上的服务暴露到公网。详见后端项目的 `scripts/deploy.sh`。

## 如何帮助录音训练

打开 `record.html` 页面，按以下步骤操作：

1. **选节目名** - 从列表中点选一个节目名（如"春草闯堂"）
2. **录音** - 点麦克风按钮，用莆仙话说出该节目名，再点一下停止
3. **保存** - 点"保存到语料库"按钮
4. **训练** - 录够 3 条以上，点"开始训练模型"按钮
5. **测试** - 训练完成后，点"用莆仙话说话测试"验证效果

每个节目名建议至少录 3 条，越多越好。录的人越多、口音越丰富，系统识别就越准。

## 如何启动服务

### 1. 启动后端 API（端口 8520）

```bash
cd puxian-dialect-training-system/scripts
python3 api_server.py
```

### 2. 启动前端网页（端口 8080）

```bash
cd ama-channel
python3 -m http.server 8080
```

### 3. 用手机访问

手机浏览器打开 `http://<电脑IP>:8080/index.html`（点播）或 `http://<电脑IP>:8080/record.html`（录音）。

## 系统怎么识别莆仙话？

系统使用三层匹配策略：

1. **文字映射** - 把 ASR 常见误识别直接映射到正确节目名（如"乾杯" → "江梅妃"）
2. **拼音模糊匹配** - 根据莆仙方言发音特点比较拼音（如 c/ch、z/zh 不分）
3. **音频对比** - 用 DTW 算法比较录音和参考库的音频特征

匹配成功后自动播放节目；不确定时弹出确认卡片让用户选择。

## 支持的节目

莆仙戏、歌仔戏、南音、木偶戏、经典电视剧、电影、音乐等共 58 个节目名。完整列表见 `program_vocab.json`。
